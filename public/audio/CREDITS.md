# Audio credits

Everything here is CC0 (public domain) **except one file under CC-BY 3.0**, which requires the
attribution given below (marked **CC-BY**). All files were downloaded from OpenGameArt.org or
Kenney.nl and re-encoded (mp3, mostly mono for effects), trimmed, loudness-normalised and, for the
ambience/wind loops, cross-faded so they loop seamlessly. Licence texts sit next to the assets
(`LICENSE-*.txt`, `engine/LICENSE.txt`, `music/LICENSE.txt`, `sfx/LICENSE-skid-cc-by.txt`).
